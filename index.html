지금 상태: 불러오는 중

구글 시트(GAS) 연결 — GitHub Pages 등에 배포했을 때
교사 코드는 이 브라우저에만 저장돼요. 학생 기기에는 넣지 마세요. 주소만 넣고 코드를 비우면 학생용(수업 화면만)으로 열려요.
배포 순서 (한 번만)
  1. 새 구글 시트 → 확장 프로그램 → Apps Script → Code.gs 내용 붙여넣기
  2. 프로젝트 설정 → 스크립트 속성: TEACHER_CODE, AI_PROVIDER(gemini 또는 claude), GEMINI_API_KEY 또는 CLAUDE_API_KEY, AI_MODEL
  3. 함수 setup 한 번 실행(권한 허용) → 시트 탭이 만들어져요
  4. 배포 → 새 배포 → 웹 앱 · 실행: 나 · 액세스: 모든 사용자 → /exec 주소 복사
  5. 이 index.html을 GitHub Pages에 올리고, 교사 컴퓨터에서 위 칸에 주소와 코드 입력
과목별 세특 작성 설정
